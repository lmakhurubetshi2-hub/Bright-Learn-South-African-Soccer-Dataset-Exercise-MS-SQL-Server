# Bright-Learn-South-African-Soccer-Dataset-Exercise-MS-SQL-Server

**A practical exercise using MS SQL Server to analyse a South African soccer dataset—designed to build SQL skills through a real-world domain.**

---

## 🧮 Project Overview  
This repository holds a hands-on exercise where I worked with a South African soccer dataset using MS SQL Server.  
The aim was to import the data, explore key metrics around teams, matches, players, and performance, and draw meaningful insights from the sport analytics domain.

---

## 📁 Repository Structure  
- `Project Discription & Raw Data/` — raw dataset files and field definitions.  
- `Data Processing/` — SQL scripts for cleaning, transformations, aggregations and analyses.  
- `README.md` — this document.

---

## 🛠 What I Did  
- Loaded the raw soccer dataset into MS SQL Server.  
- Created key analytics queries such as:   
  - Goals scored and assist
  - Goals scored per match ratio
  - Player participation counts   
- Generated the insights and documented findings.

---

## 🎯 Key Skills & Tools  
- MS SQL Server (T-SQL dialect)  
- Aggregation & grouping logic  
- Domain-specific sports analytics (soccer)  
- Translating raw data into actionable insights  
- Structuring an analytics exercise from start to finish
